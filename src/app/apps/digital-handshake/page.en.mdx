A personal portfolio and CV website showcasing work experience, education, and projects.

## Features

- Responsive design with dark mode support
- Blog, work experience, and education stored in a database and edited in a Markdown admin editor (English and German)
- Magic-link or password login for the admin area
- Skills and tech stack overview with categorized cards

## Technical details

Built with the Next.js App Router and rendered on a server. Content (blog posts, work and education entries) lives in Supabase and is edited in an admin area, so the public repository contains no personal content. Projects remain MDX files in the repository. The site uses Tailwind CSS for styling and next-themes for dark mode.
